# The Digital Detective (`digital-detective-8429`)

Explore your computer and build a mini system report. This repository documents the **Digital Detective** Diwali Independent Learning Assignment across nine sequential missions (Mission 0 through Mission 8).

Each mission is completed, documented in its own `README.md`, committed separately with a descriptive message, and pushed to GitHub before moving on to the next mission.
