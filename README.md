# The Digital Detective (`digital-detective-8429`)

Explore your computer and build a mini system report. This repository contains the completed **Digital Detective** Diwali Independent Learning Assignment, structured as nine sequential missions (Mission 0 through Mission 8).

Each mission is documented in its own `README.md` using a consistent format, and each mission was completed, committed separately with a descriptive commit message, and pushed to GitHub before starting the next mission.

## Topics Explored

- Repository setup and workspace organisation (`Mission 0`)
- Computer fundamentals, IPOS cycle, hardware/software, and everyday systems (`Mission 1`)
- Terminal navigation, safe file management, flags, pipes, and package managers (`Mission 2`)
- Operating system responsibilities, processes, storage, paths, and file permissions (`Mission 3`)
- Program execution, Python basics, and compilers vs. interpreters (`Mission 4`)
- Number systems (decimal, binary, hexadecimal), Python verification, and ASCII/UTF-8 text encoding (`Mission 5`)
- Git workflow, branching (`update-about`), and Pull Requests (`Mission 6`)
- Computer networks (LAN, MAN, WAN, DNS, routers, protocols, packet switching, client-server) (`Mission 7`)
- Final repository verification and submission checklist (`Mission 8`)

## Running the Number Converter (Mission 5)

To run the decimal-to-binary and decimal-to-hexadecimal converter from its mission folder:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a non-negative decimal integer when prompted (for example, `13`, `25`, or `255`) to see both its binary and hexadecimal representations.

## Summary of What I Learned

Through these missions, I learned how a computer processes data from input to storage, how to navigate and manage files safely in the Terminal, how the operating system coordinates processes and permissions, how Python executes code compared to compiled languages, how numbers and text are encoded in binary and hexadecimal, how Git branches and Pull Requests support clean collaboration, and how DNS, routers, and protocols deliver web pages.
