### Task 1.1 — Trace one activity using IPOS
**Chosen activity:** Typing, spell-checking, and saving a study note in a text editor.

| Stage | What happens in your example? | Possible hardware / component |
| --- | --- | --- |
| Input | I press keys on the keyboard to type words and use the trackpad to click the Save button. | Keyboard, trackpad |
| Processing | The CPU receives the keystroke signals, updates the text buffer in memory, checks spelling, and prepares the file data for saving. | CPU (processor) and RAM (memory) |
| Output | The typed characters, formatting, and "Saved" status appear on the display so I can read and verify my note. | Display screen |
| Storage | When I save the file, the updated text is written from temporary memory to permanent storage on the drive. | Solid State Drive (SSD) |

**How the activity moves across stages:** Keystrokes enter as electrical input signals, are temporarily held in RAM while the CPU processes them and renders pixels to the screen as output, and finally get written to the SSD so the note stays intact even after the computer shuts down.

## 4. My understanding
Every computing task follows the IPOS cycle: raw input is captured by input devices, transformed by the CPU and RAM during processing, presented back to the user as output, and saved in non-volatile storage when needed. Hardware provides the physical parts that do the work, while software provides the instructions—split into operating systems that manage the machine, applications that help users get work done, and utilities that maintain or inspect the system.
